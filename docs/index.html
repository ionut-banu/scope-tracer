scope-tracer

Visualize Java structured concurrency (StructuredTaskScope) task trees, lifetimes, and cancellation propagation. Zero-code-change with a Java agent, or a thin wrapper — either way you get a self-contained HTML report with SVG Gantt timelines, built from a JFR recording. Targets JDK 27+ with --enable-preview.

license: Apache-2.0

What you get

  • Per-scope Gantt timeline — what ran in parallel, at a glance
  • Nested scopes rendered indented beneath the task that spawned them
  • Critical-path highlighting — the task that determined total scope duration
  • Failure and cancellation propagation, with exception details
  • No server required — the report is a single self-contained HTML file

Try it in one command

Needs JDK 27+, curl and a POSIX shell. This downloads the agent, runs a small program with a succeeding, a failing and a slow task under it, and leaves trial.jfr and trial.html beside it. 

curl -LO https://github.com/ionut-banu/scope-tracer/releases/download/v0.5.0/scope-tracer-agent-0.5.0-agent.jar

cat > Trial.java <<'EOF'
import java.util.concurrent.StructuredTaskScope;

public class Trial {
    public static void main(String[] args) throws InterruptedException {
        try (var scope = StructuredTaskScope.open()) {
            scope.fork(() -> { Thread.sleep(50); return "profile"; });
            scope.fork(() -> { Thread.sleep(100); throw new IllegalStateException("inventory unavailable"); });
            scope.fork(() -> { Thread.sleep(5_000); return "reviews"; });
            scope.join();
        } catch (Exception e) {
            System.out.println("scope failed: " + e.getCause());
        }
    }
}
EOF

java --enable-preview --source 27 -javaagent:scope-tracer-agent-0.5.0-agent.jar=record=trial.jfr Trial.java

Or, with JBang and nothing else: jbang demo@ionut-banu/scope-tracer runs a small program with the agent attached and leaves scope-tracer-demo.html in the current directory; jbang analyze@ionut-banu/scope-tracer recording.jfr report.html turns your own recording into a report. JBang fetches JDK 27 if you have none, and asks once whether you trust the source: answer it.

Any JDK 27+ application using StructuredTaskScope gets traced — no source changes. See the README for the library wrapper (TracedScope), capture filters/sampling for production use, and full setup instructions.
